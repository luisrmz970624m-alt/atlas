```
GET  /api/tema-actual       → { id, titulo, nivel, estado, repaso, requiere }
GET  /api/leccion           → { titulo, contenido_preview, requisitos, desbloquea }
POST /api/responder/<tema>  → Crea plantilla y devuelve contenido

GET  /api/memoria           → { total, espacios: { programacion, personal, ... } }
GET  /api/auditar           → { estado, eventos_verificados, detalle }
```

### Backend (Node.js + Express)

```typescript
// web/server.js (pseudocódigo)
import express from 'express';
import { exec } from 'child_process';

const app = express();

app.get('/api/progreso', async (req, res) => {
  const output = await exec('npm run atlas -- progreso');
  res.json(parseProgreso(output));
});

app.post('/api/evaluar/:tema', async (req, res) => {
  const output = await exec(`npm run atlas -- evaluar ${req.params.tema}`);
  res.json(parseEvaluacion(output));
});
```

## 3. Copias de Seguridad Automáticas (V0.9.3)

### Características

- [ ] Backup diario automático (00:00 UTC)
- [ ] Historial de 30 días
- [ ] Compresión (.tar.gz)
- [ ] Ubicación configurable (local, cloud)
- [ ] Restauración de un clic
- [ ] Verificación de integridad

### Estructura de backup

```
backups/
├── 2026-09-23-atlas.tar.gz
│   ├── datos/registro.jsonl
│   ├── datos/memoria.db
│   ├── laboratorio/
│   └── MANIFEST.json
├── 2026-09-22-atlas.tar.gz
└── ...
```

### Script de backup

```bash
#!/bin/bash
# web/scripts/backup.sh

BACKUP_DIR="${ATLAS_BACKUP_DIR:-./backups}"
DATE=$(date +%Y-%m-%d)
BACKUP_FILE="$BACKUP_DIR/$DATE-atlas.tar.gz"

mkdir -p "$BACKUP_DIR"

# Crear backup
tar -czf "$BACKUP_FILE" \
  datos/registro.jsonl \
  datos/memoria.db \
  laboratorio/

# Verificar integridad
tar -tzf "$BACKUP_FILE" > /dev/null && \
  echo "✅ Backup $DATE verificado" || \
  echo "❌ Backup $DATE corrompido"

# Limpiar backups > 30 días
find "$BACKUP_DIR" -name "*.tar.gz" -mtime +30 -delete
```

### Cron para automatización

```bash
# Ejecutar diario a las 00:00 UTC
0 0 * * * /home/luisangel/atlas/web/scripts/backup.sh >> /var/log/atlas-backup.log 2>&1
```

## 4. Integración en Atlas CLI (V0.9.4)

### Nuevos comandos

```bash
npm run atlas -- web              # Inicia servidor web (puerto 3000)
npm run atlas -- web --port 8080  # Puerto custom
npm run atlas -- backup           # Backup manual
npm run atlas -- restore <fecha>  # Restaurar desde backup
npm run atlas -- audio-gen        # Generar audio de lecciones
```

### Configuración

```json
// atlas.config.json
{
  "web": {
    "port": 3000,
    "host": "localhost"
  },
  "backup": {
    "enabled": true,
    "time": "00:00",
    "dir": "./backups",
    "retention_days": 30
  },
  "audio": {
    "enabled": true,
    "provider": "google-tts",
    "language": "es-ES",
    "voice": "es-ES-Neural2-A"
  }
}
```
