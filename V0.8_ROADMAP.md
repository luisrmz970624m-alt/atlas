## 1. Simulador de Trading Básico

### Características

**Portafolio:**
- Capital inicial configurable (default: $10,000)
- Posiciones activas (símbolo, cantidad, precio promedio)
- Historial de órdenes (compra/venta con timestamp)
- Efectivo disponible

**Órdenes:**
- Compra: `$ atlas orden comprar BTC 0.5 @ 45000`
- Venta: `$ atlas orden vender BTC 0.5 @ 48000`
- Cancelar: `$ atlas orden cancelar <id>`
- Ver: `$ atlas orden listar`

**Validaciones:**
- Suficiente capital para comprar
- Suficiente cantidad para vender
- Precios positivos
- Cantidades válidas

### Estructura de datos

```typescript
// datos/trading.db (SQLite)
CREATE TABLE portafolios (
  id TEXT PRIMARY KEY,
  usuario_id TEXT,
  capital_inicial REAL,
  capital_actual REAL,
  created_at TEXT,
  updated_at TEXT
);

CREATE TABLE posiciones (
  id TEXT PRIMARY KEY,
  portafolio_id TEXT,
  simbolo TEXT,        // BTC, ETH, AAPL, etc
  cantidad REAL,
  precio_promedio REAL,
  created_at TEXT,
  updated_at TEXT
);

CREATE TABLE ordenes (
  id TEXT PRIMARY KEY,
  portafolio_id TEXT,
  tipo TEXT,           // "compra" | "venta"
  simbolo TEXT,
  cantidad REAL,
  precio REAL,
  estado TEXT,         // "ejecutada" | "pendiente" | "cancelada"
  comision REAL,
  executed_at TEXT
);

CREATE TABLE precios (
  id TEXT PRIMARY KEY,
  simbolo TEXT,
  fecha DATE,
  apertura REAL,
  cierre REAL,
  minimo REAL,
  maximo REAL,
  volumen INTEGER
);
```

### Métricas calculadas

- **PnL Realizado:** ganancia/pérdida de órdenes ejecutadas
- **PnL No realizado:** ganancia/pérdida de posiciones abiertas
- **ROI:** Return on Investment (ganancia / inversión)
- **Win Rate:** % de órdenes ganadoras
- **Ratio Ganancia/Pérdida:** promedio de ganancias / promedio de pérdidas
- **Máxima Pérdida:** peor operación
- **Máxima Ganancia:** mejor operación
- **Drawdown:** caída máxima desde pico

## 4. Histórico de Precios

### Fuentes de datos

**Opción 1: Datos sintéticos (para desarrollo)**
```typescript
// Generar precios realistas con Random Walk
function generarPreciosHistoricos(simbolo: string, dias: number) {
  let precio = preciosIniciales[simbolo];
  const datos = [];
  
  for (let i = 0; i < dias; i++) {
    const cambio = (Math.random() - 0.5) * 0.02; // ±1% diario
    const nuevoP = precio * (1 + cambio);
    
    datos.push({
      fecha: new Date(Date.now() - (dias-i)*86400000).toISOString().split('T')[0],
      apertura: precio,
      cierre: nuevoP,
      minimo: Math.min(precio, nuevoP),
      maximo: Math.max(precio, nuevoP),
      volumen: Math.floor(Math.random() * 1000000)
    });
    
    precio = nuevoP;
  }
  
  return datos;
}
```
