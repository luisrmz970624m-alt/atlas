# Atlas V0.8 — Arquitectura: Competencia en Tiempo Real

**Modelo:** Atlas es un autómata que mina, estudia y tradea en paralelo, compitiendo contra el usuario.

---

## 1. Sistema de Energía

Atlas tiene **100 energía/día** que se divide entre actividades:

```typescript
interface EstadoAtlas {
  id: string;
  nivel: number;           // 1-100 (sube con ganancias)
  energia_hoy: number;     // 0-100 (se regenera cada 24h)
  dinero_minado: number;   // ETH acumulado
  dinero_ganado: number;   // USD en ganancias de trading
  reputacion: number;      // Promedio de performance
  bots_activos: Bot[];
  estudios_completados: number;
}

interface AsignacionEnergia {
  estudiar: number;        // % de energía en aprender
  minar: number;           // % de energía en minería
  tradear: number;         // % de energía en ejecución de bots
}

// Default: 40% estudiar, 30% minar, 30% tradear
```

### Cómo se consume:

```
Actividad          | Energía | Resultado
─────────────────────────────────────────
Leer lección       | 5       | +1 conocimiento
Ejercicio práctico | 10      | +5 conocimiento si apruebas
Minar criptos      | 1/bloque| +$0.001 ETH
Ejecutar bot       | 3/orden | +/- dinero según resultado
```

## 2. Sistema de Minería

Mientras Atlas mina, genera **ETH simulado**:

```typescript
interface MineriaAtlas {
  energia_asignada: number;      // % de energía diaria
  hash_rate: number;             // Mejora con nivel
  eth_por_hora: number;          // Depende de hash_rate
  dificultad: number;            // Aumenta con tiempo
  generado_hoy: number;          // ETH acumulado hoy
}

// Fórmula:
// eth_por_hora = (energia_asignada / 100) * (0.001 + nivel * 0.0005) * (1 / dificultad)
// Ejemplo: Nivel 10, 30% energía → ~0.003 ETH/hora

// A final de día:
// - ETH se vende en el mercado simulado al precio actual
// - El $ se suma a capital de trading
```

## 3. Bots Autónomos de Atlas

Atlas ejecuta múltiples bots en **tiempo real**, cada uno con estrategia diferente:

```typescript
interface Bot {
  id: string;
  nombre: string;
  estrategia: 'buy-and-hold' | 'dca' | 'momentum' | 'mean-reversion';
  capital_asignado: number;     // USD
  energia_por_ejecucion: number; // 3 por orden
  simbolos: string[];           // BTC, ETH, etc
  estado: 'activo' | 'parado' | 'evolucionando';
  
  // Performance
  trades_ejecutados: number;
  ganancia_total: number;
  win_rate: number;
  ultimo_trade: string;         // ISO timestamp
}

// Bots que Atlas crea con experiencia:
// Nivel 1: buy-and-hold básico
// Nivel 5: DCA (dollar-cost averaging)
// Nivel 10: momentum siguiendo tendencias
// Nivel 20: mean-reversion + stop-loss
// Nivel 50: combinación adaptativa (ML simple)
```

### Ejecución en tiempo real:

```
Cada minuto:
  1. Obtener precio actual de BTC, ETH, etc
  2. Para cada bot activo:
     - Evaluar señal de su estrategia
     - Si hay señal + suficiente energía + capital:
       → Ejecutar orden
       → Registrar en historial
       → Descontar energía
  3. Actualizar portafolio de Atlas
  4. Mostrar cambios al usuario
```

## 11. Requisitos de Batería para Minería (V0.9+)

**Cuando Atlas tenga apps de PC y teléfono:**

El motor de minería **solo se activa** si se cumple UNO de estos:
- ✅ Batería del teléfono al **100%**
- ✅ Batería de la PC al **100%**
- ✅ Teléfono conectado al cargador (cualquier %)
- ✅ PC conectada a alimentación (cualquier %)

**Razón:** Proteger la batería de dispositivos móviles

**Implementación:**
```typescript
interface CondicionesBateria {
  dispositivo: 'pc' | 'telefono';
  porcentaje_bateria: number;
  conectado_cargador: boolean;
  puede_minar: boolean;
}

function puede_activar_mineria(bateria: CondicionesBateria): boolean {
  return (
    bateria.porcentaje_bateria === 100 ||
    bateria.conectado_cargador
  );
}

// El usuario ve:
// "⚠️ Minería pausada: batería al 87% y no conectado al cargador"
// "✅ Minería activa: PC conectada a alimentación"
// "✅ Minería activa: teléfono al 100% de batería"
```

**Estados posibles:**
```
MINERÍA ACTIVA ✅
├─ PC: 100% batería O conectada a cargador
└─ Teléfono: 100% batería O conectado a cargador

MINERÍA PAUSADA ⏸️
├─ Batería al 99% y sin cargador
└─ Se reanuda automáticamente cuando se cumpla condición

MINERÍA SUSPENDIDA ❌
├─ Si baja a 50% (protección de batería)
└─ Atlas continúa estudiando y tradiando
```
