LIMITATIONS (What Graphify CANNOT Do)
═════════════════════════════════════════════════════════════════

✗ Runtime performance monitoring (static analysis, not execution)
✗ Parameter sensitivity analysis (requires backtest data, not code structure)
✗ Real-time strategy tuning (built for background updates, not sub-second queries)
✗ Trade execution optimization (Graphify doesn't run trades)
✗ Market regime prediction (pure structural analysis, no market intelligence)

These need: metrics database, backtesting harness, live market feeds — NOT a graph.

CONCLUSION
═════════════════════════════════════════════════════════════════

Graphify is a DOCUMENTATION + ARCHITECTURE VERIFICATION tool.
It excels at: "How does this complex system connect?"
It fails at: "Will this strategy make money?"

For ATLAS Phase 3+:
  ✅ Use for: Architecture clarity, docs verification, idempotence testing
  ❌ Don't use for: Backtesting, parameter tuning, live trading
